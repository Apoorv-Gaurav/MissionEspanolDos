# 🇪🇸 Aventura en España

**Learn Spanish through exploration, interaction, and gameplay!**

Aventura en España is a 2D educational game developed using Unity. It combines interactive environments with Spanish vocabulary challenges, allowing players to learn and practice everyday Spanish words while exploring different locations and completing objectives.

Instead of memorizing vocabulary from a list, players learn through interactive tasks that encourage them to identify objects, recognize body parts, explore a city, and discover everyday places and items.

## 🎮 About the Project

The goal of Aventura en España is to make learning Spanish more engaging, interactive, and enjoyable through game-based learning.

Players explore different environments, receive objectives in Spanish, and interact with the correct objects to complete each level. The game is designed for Spanish learners who want to practice vocabulary in a simple and fun way.

### ✨ Features

- **Interactive 2D gameplay** — Explore environments and interact with objects.
- **Spanish vocabulary practice** — Learn words associated with everyday objects, body parts, places, and groceries.
- **Objective-based challenges** — Complete tasks by finding the correct target.
- **Multiple levels** — Practice vocabulary across different environments.
- **Keyboard-based controls** — Move around and interact with targets.
- **Beginner-friendly learning** — Learn Spanish through practical examples and repetition.

## 🗺️ Game Levels

The game includes vocabulary-based environments such as:

| Level | Environment | Learning Focus |
|---|---|---|
| Level 1 | Classroom | Identifying classroom objects |
| Level 2 | Body | Learning Spanish body-part vocabulary |
| Level 3 | City | Recognizing places around a city |
| Level 4 | Grocery Shops | Learning grocery items and shop vocabulary |

The exact level availability may depend on the version of the game you download.

## 🕹️ Controls

| Key | Action |
|---|---|
| `W` | Move up |
| `A` | Move left |
| `S` | Move down |
| `D` | Move right |
| `E` | Interact with a target or complete an objective |

Some levels may also support mouse interaction for selecting objects.

**Tip:** Read the on-screen objective carefully, move close to the target, and press `E` when prompted.

## ⬇️ Download the Game

You do not need to install Unity to play the released Windows version.

1. Open the project's **[Releases](../../releases/latest)** page.
2. Download the Windows release ZIP file from the **Assets** section.
3. Wait for the download to finish.
4. Extract the ZIP file using Windows File Explorer.
5. Open the extracted folder.
6. Run the game's `.exe` file to launch Aventura en España.

> **Important:** Extract the entire ZIP before running the game. Keep the executable and all accompanying files and folders together. Do not move the executable out of its build folder.

## ▶️ Running the Release on Windows

After extracting the ZIP:

1. Locate the game executable, usually named `Aventura en España.exe` or `AventuraEnEspana.exe`.
2. Double-click the executable.
3. If a Unity launch window appears, choose the desired resolution and display mode, then click **Play**.
4. Start the game and follow the on-screen instructions.

If Windows displays a security warning, verify that the file came from the official release published by this repository before deciding whether to run it.

### Troubleshooting

**The game does not launch**
- Extract the ZIP completely.
- Make sure you are running the executable from the extracted folder.
- Check that your system meets the build's requirements.

**The game opens but controls do not respond**
- Click inside the game window.
- Try the movement keys and the interaction key again.

**A level or button does not work correctly**
- Return to the main menu and try again.
- If the issue persists, report it in the repository's Issues section with the level name and steps to reproduce it.
